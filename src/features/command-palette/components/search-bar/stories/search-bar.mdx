# Search bar

The search bar edits the palette query and provides an inline Clear search control.
The parent command palette owns the separate Close modal button at its top right.
It does not filter or render results itself: the Available Commands component
subscribes to the same query and derives the visible list.

## Responsibilities

`SearchBar` renders the input and icons. Its primary hook, `useSearchBar`, owns the
query subscription, change and clear handlers, and input ref. The hook schedules
focus when the component mounts and cancels the pending timer on unmount.

The component takes no props. It reads the palette provider nearest to it.

## State and behaviour

- The input displays the palette store's `query`, including changes made elsewhere.
- Typing calls `setQuery`. A changed query also resets `activeIndex` to zero in the same store update.
- The input preserves the user's text. Trimming and case normalisation happen in the result-filtering utility.
- Clear search appears only for a nonempty query. It clears the query, resets the active index, and returns focus to the input without closing the palette.
  Clearing keeps the palette open. Closing and lifecycle reset behaviour are covered
  by the assembled command palette, which owns visibility.

## Integration

The search bar needs palette and workspace providers: the query and navigation
live in the palette store, while Enter updates workspace selection. Storybook's
global preview supplies both; fixtures override both with isolated stores and
in-memory workspace persistence.

that surface around standalone examples rather than assuming that a theme will
paint the component's background.

## Keyboard and accessibility

The input is named “Search commands”. The SearchX clear button is named “Clear search”. The search and clear icons
are decorative.

ArrowUp and ArrowDown wrap the active highlight through the current filtered
results. Enter selects that result, records it in workspace history, and closes
the palette. These handlers run only on the search input while the palette is
open and ignore IME composition. Empty results do not select or close anything.
Escape comes from the mounted palette keyboard hook, not an isolated search bar.
